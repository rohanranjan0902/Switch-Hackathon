## Production Recording Tips

1. **Resolution**: Record at 1080p (1920x1080) at 60 FPS for crisp code diff readability.
2. **Audio**: Use a clear microphone with background noise suppression.
3. **Pacing**: Maintain an energetic, confident, authoritative tone throughout.
4. **Captions**: Add subtitle overlays for key technical terms (`Switch Agent Protocol`, `Unified Git Diff`, `Human-in-the-Loop Boundary`).
